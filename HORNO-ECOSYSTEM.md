This open-source URL metadata and social profile fetcher is designed as reusable infrastructure for products that need to turn a public URL into structured, editable data. The same class of enrichment pattern is used across live products connected to the **HORNO ecosystem**.

## HORNO Space

[HORNO Space](https://space.horno.net) is the social identity and discovery layer of HORNO Network. It combines a public creator profile, bio link, digital business card, smart links, articles, products and services, referral links, QR sharing, analytics, verification, community discovery and live experiences into one public URL.

The same type of URL-enrichment workflow documented in this repository helps products like HORNO Space transform raw external URLs into richer metadata for **smart-link cards, profile blocks, social discovery and indexed public profiles**.

Explore HORNO Space at **[space.horno.net](https://space.horno.net)**.

## Why URL enrichment matters across the ecosystem

A single public URL can contain enough information to pre-fill or enrich a listing, profile, smart link, project page or directory entry. This repository extracts and normalizes data such as titles, descriptions, Open Graph metadata, canonical URLs, images, favicons, public social links, structured data and available profile information.

That pattern is useful across:

- decentralized infrastructure directories and ecosystem pages;
- HORNO Network project and community discovery;
- HORNO Space creator and professional profiles;
- bio-link and smart-link cards;
- public project and product listings;
- community referrals and profile onboarding;
- SEO-friendly public pages;
- social profile enrichment;
- link previews and URL unfurling;
- AI and RAG pipelines that ingest public URLs;
- startup, product, creator and Web3 directories.
