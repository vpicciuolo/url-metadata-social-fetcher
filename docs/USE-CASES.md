# Use cases

If your workflow begins with **“give me the URL to the thing”**, this toolkit can often reduce manual entry.

## Discovery and ranking
- Outbid-style bid-to-position websites
- paid/public leaderboards
- startup launch boards
- SaaS/AI/developer-tool directories
- app/product rankings
- creator/music/brand charts
- sponsored resource lists
- community discovery boards

## Profiles
- user profiles
- creator/influencer profiles
- artist/DJ/musician profiles
- founder/company/public-person profiles
- portfolio builders
- link-in-bio products
- claim-your-profile flows
- social import/onboarding

## Marketplaces
- freelancer/creator marketplaces
- influencer campaign platforms
- service/gig listings
- agency/vendor/talent directories
- plugin/integration marketplaces

## Products and projects
- startup databases
- product catalogs
- brand intelligence
- ecosystem maps
- accelerator/investor portfolios
- partner/sponsor directories
- crowdfunding project intake

## Media/content
- rich link previews
- chat unfurling
- bookmark managers
- content/news curation
- podcast/music/video directories
- newsletter link cards

## Sales/internal
- CRM URL import
- public lead/company cards
- partner/vendor onboarding
- account research cards
- brand/logo autofill
- external resource inventories

## SEO/AI/automation
- Open Graph debuggers
- metadata QA
- canonical discovery
- JSON-LD extraction
- bounded text extraction before RAG/LLM processing
- agent tools that receive untrusted URLs
- website-to-JSON utilities
- metadata change monitoring inputs

## Important
This package is not a browser automation framework and does not bypass access controls. Official APIs may be preferable or required for some data and business cases.
