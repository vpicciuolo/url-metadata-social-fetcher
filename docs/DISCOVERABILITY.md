## Social preview
Use the included `assets/hero.svg` as the design source and export a 1280×640 PNG for GitHub Social Preview.

## First release
Create `v1.0.0.1 — Initial public release` using `CHANGELOG.md` as release notes.

## External discovery
Link the repo from BeHot.now/HRN technical pages, founder social posts and your GitHub profile. Publish to npm if you want package-search discovery too. Avoid keyword stuffing; keep adding real examples, releases and tests.
